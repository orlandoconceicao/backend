# Estudos de Backend com Django

Repositório de estudos progressivos sobre desenvolvimento backend com Python e Django, desde a preparação do ambiente até modelos, ORM e testes.

## Conteúdo

- Configuração do ambiente de desenvolvimento e do VS Code
- Ambientes virtuais Python
- Integração entre Django, Git e GitHub
- URLs e views
- Renderização de templates
- Arquivos estáticos
- Herança de templates
- Models e Django ORM
- Testes com Django
- Projetos práticos

## Estrutura

O conteúdo está separado em diretórios numerados, permitindo acompanhar a evolução dos estudos em ordem. A pasta `projetos` concentra aplicações utilizadas para praticar os conceitos apresentados nos módulos.

## Como utilizar

Clone o repositório e acesse o módulo desejado:

```bash
git clone https://github.com/orlandoconceicao/backend.git
cd backend
```

Como os exemplos são independentes, consulte a estrutura e os arquivos de cada módulo antes da execução.
